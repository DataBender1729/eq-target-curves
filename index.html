Instructions:

Pick four Hz/dB reference points and 3 functions to blend between them. Add EQing to season.
Click generate to create a target curve file to download and use in your room correction software (e.g., Dirac Live).

Curve types:
  • Linear: Just a line from the starting dB to the end dB (will look curved in log Hz-space).
  • Log-Linear: A straight drop in logarithmic space (will look straight in log Hz-space).
  • Curved: Very similar to the popular harman curves. Amplifies the low end of the curve and then drops quickly.
  • Cosine: Drops to the halfway dB point after half the Hz-distance in a (co)-sine shape

Additional EQing: Use a preset or paste a PEQ file e.g. from REW EQ tool. This representation uses the "a0=1" convention and 96kHz sampling. Adding the same EQ filter multiple times will stack them.
  • Dialog Lift: Makes dialog stand out more from sound effects and background material by increasing energy across the core vocal range by 1.5 or 3dB. Most useful when applied to the center channel in lieue of boosting the center across the board.


If you want to apply PEQ filters to an arbitrary target curve not from this tool, go to Target Curve PEQ tool.
